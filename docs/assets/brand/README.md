# Logo files

These SVG files are the approved Whalory logos, copied byte for byte from the Whalory identity kit. The `primary` files are for light backgrounds, and the `reverse` files are for dark ones.

| File | Where it appears |
|---|---|
| `whalory-wordmark-en-*.svg` | The top of the English front page, alone. The English wordmark is never set beside the symbol. |
| `whalory-fa-horizontal-*.svg` | The top of the Persian front page: the approved Persian lockup. |
| `whalory-b05-*.svg` | The foot of both front pages, and the social preview image: the bilingual lockup. |
