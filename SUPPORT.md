# Getting help

You can write in English or Persian.

## Read first

- Install steps for every host: [docs/INSTALL.md](docs/INSTALL.md).
- The user guide, with a troubleshooting section: [GUIDE.en.md](skills/whalory/GUIDE.en.md#troubleshooting), or [GUIDE.fa.md](skills/whalory/GUIDE.fa.md) in Persian.
- The per-host guides on the website, each with the date it was checked: [the download page](https://whalory.com/download/).

## Whalory Core

Core is supported through this repository's issues, and has no other support channel. Pick the form that fits:

| Form | Use it when |
|---|---|
| [Bug report](https://github.com/gilebehnam/whalory/issues/new?template=bug_report.yml) | A script crashes, an MCP tool fails, or the skill does something the guide says it won't |
| [Linter false positive](https://github.com/gilebehnam/whalory/issues/new?template=linter_false_positive.yml) | A rule flags text that is correct |
| [Host install problem](https://github.com/gilebehnam/whalory/issues/new?template=host_install.yml) | An install route in the docs fails on your host |
| [Feature request](https://github.com/gilebehnam/whalory/issues/new?template=feature_request.yml) | You want a new rule, playbook, host, or option |

Before you open one, please search the open and closed issues. Issues are public, so leave out client copy you may not share.

## Paid editions

Support for Whalory Pro and Studio does not go through this repository. The license you receive when you buy describes its channel and its response time, which are still being settled. For downloads and license keys, use [the account page](https://whalory.com/account/) on the Whalory website. Never post a license key in an issue.

## Security and conduct

- To report a vulnerability, follow [SECURITY.md](SECURITY.md). Please don't open an issue.
- To report a breach of the [Code of Conduct](CODE_OF_CONDUCT.md), use the private routes it describes. A conduct report sent through the security form is never published.
