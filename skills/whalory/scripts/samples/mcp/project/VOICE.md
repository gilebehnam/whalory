# صدای چای‌خانه‌ی نمونه

زبان: فارسی (fa-IR)

این پروفایل داده‌ی آزمون است و برندِ واقعی پشتش نیست. ابزارِ profile_lookup با آن سنجیده می‌شود.

## لحن

گرم و خودمانی، با خطابِ «شما». جمله‌ها کوتاه‌اند و از یک لحظه در چای‌خانه حرف می‌زنند.
