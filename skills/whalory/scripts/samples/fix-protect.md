# راهنمای دم‌کردن

برای شروع، `lint_fa.py --fix "draft.txt"` را اجرا کن, بعد نتیجه را بخوان.

```python
msg = "سلام, دنیا"  # کد دست نمی‌خورد
```

این متن را از [صفحه‌ی "چای"](https://example.com/chai?a=1,b=2 "عنوان, پیوند") بخوان, "لطفاً".

The tool prints "ok, done" when finished; see https://example.com/fa/"x".

این چای را "اردیبهشت" چیدیم, و همان هفته — در باغ — خشک کردیم.
